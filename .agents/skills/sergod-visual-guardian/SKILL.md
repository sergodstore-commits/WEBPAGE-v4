# Sergod Visual Guardian

1. Leer `docs/CURRENT/11-DISENO-E-IDENTIDAD-VISUAL.md`.
2. Tratar `apps/web/src/styles/base.css` como estructura neutral, nunca como dirección estética.
3. No recuperar, inferir ni reutilizar propuestas visuales retiradas del repositorio.
4. No crear logos alternativos ni símbolos que puedan confundirse con la marca.
5. Logo oficial: no regenerar, recolorear, deformar, recortar ni mejorar destructivamente.
6. Toda nueva dirección visual requiere aprobación expresa del propietario antes de considerarse vigente.
7. Verificar escritorio/móvil, foco, contraste, overflow, carga y peso de recursos.
