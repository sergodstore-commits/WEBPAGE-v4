# Stage 06-release — release controlado

## Objetivo

Promover solo la versión aceptada, ejecutar migraciones y smoke de producción, confirmar observabilidad/rollback y cerrar la misión.

## Condición de cierre

- Todos los gates locales y externos PASS con evidencia.
- Hashes/manifiestos regenerados para el artefacto exacto liberado.
- Git limpio, migraciones protegidas intactas y documentación actual.
- Producción verificada sin declarar éxito anticipado.
