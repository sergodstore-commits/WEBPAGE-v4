# Stage 05-final-external-acceptance — consolidar evidencia externa

## Objetivo

Ejecutar el orquestador de aceptación, resolver todos los `DEFERRED_EXTERNAL` y verificar que cada PASS tenga evidencia reciente del entorno requerido.

## Condición de cierre

No avanzar con deuda externa, credenciales ausentes, pruebas omitidas o hallazgos abiertos. Actualizar IMPLEMENTATION-STATUS con enlaces/identificadores de evidencia sin incluir secretos.
