# 08 — Roadmap y fases

El roadmap se ejecuta mediante `.codex-mission/`. El árbol objetivo no autoriza saltarse dependencias.

Orden macro:

1. baseline y conformidad CURRENT;
2. inventario visual y design system;
3. Orders y checkout definitivo;
4. Payments core + Flow;
5. fulfillment;
6. cuenta cliente;
7. Admin;
8. web pública comercial;
9. contenido editorial;
10. integración visual;
11. email transaccional;
12. E2E e integración transversal;
13. QA visual/responsive;
14. hardening;
15. aceptación externa final agrupada;
16. release y cierre de misión.

Los stages se revelan progresivamente mediante `STATE.json`. Codex puede subdividir el stage actual bajo `.runtime/` sin adelantar trabajo futuro ni ampliar alcance.
